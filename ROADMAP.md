# PC Hardware Atlas Roadmap

| Phase | Focus | Main deliverable | Status |
|---|---|---|---|
| 1 | Project foundation | Responsive Three.js PC scene with orbit, zoom, reset, eight selectable component groups, and component details | Complete |
| 2 | Inspection tools | Exploded view, isolate, hide/show, focus camera, and clearer 3D labels | Complete |
| 3 | Hardware knowledge | Richer component lessons, ports and connections, search, filters, and a glossary | Next |
| 4 | Guided learning | Simple-English guided tours, lesson steps, checkpoints, and short quizzes | Planned |
| 5 | Build-a-PC challenge | Drag-and-place assembly activity, installation order, hints, and simplified compatibility rules | Planned |
| 6 | Student progress | Local progress saving, XP, badges, results, accessibility improvements, and localization-ready content | Planned |
| 7 | Performance and offline use | Low-spec mode, optimized 3D assets and bundle, offline caching, and installable PWA support | Planned |
| 8 | Release | Cross-device testing, content review, documentation, and GitHub Pages deployment | Planned |

## Scope rule

Complete and test one phase before starting the next. Preserve working features and avoid adding cloud services until they provide a clear learning benefit.
